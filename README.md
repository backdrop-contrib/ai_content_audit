# AI Content Audit

Review published pages for redundant, outdated, or trivial content. Find exact duplicates and prioritize pages for review using age and optional traffic data. Administrators approve proposed changes before the module applies them.

## Requirements

Backdrop CMS 1.x, PHP 8.2 or later, and [AI](https://github.com/backdrop-contrib/ai). A text model is optional for the scan and required for AI summaries or draft edits. Exact duplicate detection works without AI Search.

## Installation

1. Install and enable the module using the official [Backdrop CMS instructions](https://backdropcms.org/user-guide/modules).
2. Open **AI Content Audit** at `admin/config/ai/content-audit` and choose the content types to scan under **Settings**.

See the [module wiki](https://github.com/backdrop-contrib/ai_content_audit/wiki) for setup, use, and troubleshooting.
